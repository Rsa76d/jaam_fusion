# Тестова прошивка JAAM 5.1.2-b3-lux8 (яскравість)

Збірка з гілки `lux8-brightness`. Це тестова версія, не офіційна. Обговорення: https://github.com/J-A-A-M/jaam_fusion/issues/101

## Який файл брати

| Плата | Файл |
|---|---|
| ESP32 | `JAAM_5.1.2-b3-lux8.bin` |
| ESP32-C3 | `JAAM_c3_5.1.2-b3-lux8.bin` |

**Не плутай:** файл для ESP32 не можна прошивати в C3 і навпаки.

## Як прошити (esptool-js у браузері)

Стирати пам'ять **не треба**: налаштування (Wi-Fi, яскравість, регіон) збережуться.

| Файл | Адреса |
|---|---|
| `boot_app0.bin` | `0xe000` |
| `JAAM_….bin` (ваша плата) | `0x10000` |

Завантажувач (bootloader) і таблицю розділів **не чіпайте**, особливо на ESP32-C3 (його завантажувач живе за адресою `0x0`, перезаписувати його не можна).

## Що перевірено
ESP32 і ESP32-C3, екран SH1106, датчик BH1750. Екрани SSD1306 і SH1107 не перевірені. Пишіть про результати в Issue.

Відкат: прошийте офіційну версію 5.1.2-b3 тим самим способом.
